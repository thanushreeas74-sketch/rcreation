MY PORTFOLIO WEBSITE
=====================

Technologies:
- HTML5
- CSS3
- JavaScript

HOW TO RUN:
1. Extract the ZIP file.
2. Open the portfolio folder.
3. Double-click index.html.
4. The portfolio will open in your web browser.

FILES:
- index.html  -> Website structure/content
- style.css   -> Design and responsive layout
- script.js   -> Navigation, contact form message, and back-to-top button
- images/     -> Add your profile/project images here

CUSTOMIZATION:
Replace:
- "Your Course" with your course
- College/school names
- Email and phone number
- Project names and descriptions
- Certificate information
- Location
- "YN" in the profile circle with your initials

IMPORTANT:
The contact form is a front-end demo. It does not send email to a real inbox.
To receive messages, connect it to a backend or a form service.
